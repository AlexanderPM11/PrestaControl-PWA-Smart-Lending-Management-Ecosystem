PRESTACONTROL · BACKUP / RECOVERY

Restauración completa desde un backup

El administrador carga un archivo cifrado .pca; el backend lo valida, descifra y restaura el volcado completo en MySQL.

Qué contiene el archivo

El backup cifrado contiene el volcado completo de MySQL, incluyendo tablas, relaciones, usuarios, configuraciones, rutinas, eventos y triggers.

Precaución

Restaurar reemplaza la información actual. Conviene generar un backup nuevo antes de iniciar la operación.
